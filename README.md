## 📂 System Overview

This repository contains the source code for my personal portfolio, designed as a **"Neural Operating System."** It moves away from traditional static designs, offering an immersive, interactive experience that reflects my expertise in **Artificial Intelligence** and **Complex Systems**.

### ⚡ Key Features
* **🎨 Cyberpunk/Terminal Aesthetic:** Dark mode interface with neon accents and "glitch" effects.
* **🍱 Bento Grid Layout:** Modular, responsive grid system for showcasing projects.
* **✨ Interactive UI:** Kinetic typography, hover states, and "system boot" animations.
* **📱 Fully Responsive:** Optimized for both desktop command centers and mobile devices.

## 💻 Local Installation

Want to explore the source code? Run the system locally:

1.  **Clone the Repository**
    ```bash
    git clone [https://github.com/NavneetSharmaProgrammer/NavneetSharmaProgrammer.github.io.git](https://github.com/NavneetSharmaProgrammer/NavneetSharmaProgrammer.github.io.git)
    cd NavneetSharmaProgrammer.github.io
    ```

2.  **Install Dependencies**
    ```bash
    npm install
    ```

3.  **Initialize System (Run Dev Server)**
    ```bash
    npm run dev
    ```
